# Week 1 – Python Fundamentals

## Overview

Week 1 focused on building a strong foundation in Python programming. Throughout the week, I practiced basic programming concepts, problem-solving, data structures, functions, loops, file handling, and Git organization.

The goal was to write small programs independently and understand how different Python concepts can be combined to solve problems.
